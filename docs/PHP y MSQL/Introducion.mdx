# Introducción

**PHP** es un lenguaje de programación del lado del servidor que se utiliza principalmente para el desarrollo web. Permite crear dinámicas en sitios web al procesar 
datos en el servidor antes de que se envíen al navegador del cliente. PHP puede interactuar con bases de datos, generando contenido HTML de manera dinámica y 
permitiendo la creación de aplicaciones web complejas.

**MySQL**, por otro lado, es un sistema de gestión de bases de datos relacional, que almacena datos de manera estructurada y permite realizar operaciones como la consulta, 
actualización y eliminación de datos. MySQL es comúnmente utilizado en conjunto con PHP, ya que permite a los desarrolladores almacenar y recuperar información 
para utilizarla en sus aplicaciones web.

En conjunto, PHP y MySQL son herramientas poderosas para desarrollar aplicaciones web interactivas y basadas en datos. 

:::note
No se requiere experiencia previa en programación 
:::
