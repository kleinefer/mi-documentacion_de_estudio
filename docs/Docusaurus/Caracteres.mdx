## 1. Caracteres básicos de Markdown

### 1. Encabezados

- Los `#` definen los tamaños de los títulos.  
  Entre más uses, más pequeño será el texto.

  **Ejemplo:**

  - `# Título grande`
  - `## Título mediano`
  - `### Título pequeño`


---
### 2. Listas  
- El guion `-` crea viñetas.

  **Ejemplo:**

  - Ejemplo de viñeta
    - Si agregas dos espacios antes del guion, obtienes una subviñeta.

- Los números seguidos de un punto crean listas ordenadas.

  **Ejemplo:**

  1. Primer punto
  2. Segundo punto
  3. Tercer punto

---

### 3. Negrilla

- Los asteriscos `**` sirven para poner texto en **negrilla**.

  **Ejemplo:**

  `**Texto en negrilla**`

  Resultado:

  **Texto en negrilla**

- Los guiones bajos dobles `__` también sirven para poner texto en **negrilla**.

  **Ejemplo:**

    
  `__texto__` 

  Resultado:

    __texto__


---
### 4. Cursiva
  - Los guiones bajos simples `_` o los asteriscos `*` ponen texto en *cursiva*.

**Ejemplo:**

`_texto_`

Resultado:

*texto*

---
### 5. Citas

- El símbolo `>` crea citas.

**Ejemplo:**

`> Esto es una cita`

Resultado:

> Esto es una cita

--- 
### 6. Tablas 

- Las tablas se crean usando `|` y `-`.

**Ejemplo:**

```md
| Columna 1 | Columna 2 |
|-----------|-----------|
| Dato A    | Dato B    |
| Dato C    | Dato D    |
```

Resultado:

| Columna 1 | Columna 2 |
|-----------|-----------|
| Dato A    | Dato B    |
| Dato C    | Dato D    |

## 2. Código y enlaces

### 1. Inline code

- Las comillas invertidas `` ` `` se usan para mostrar texto en un recuadro de código.

  **Ejemplo:**

  `` `texto en recuadro` ``

  Resultado:

  `texto en recuadro`

---
### 2. Bloques de código
- Para bloques de código más grandes, usa tres comillas invertidas.

**Ejemplo:**

```md

``` javascript
function saludo() {
  console.log("¡Hola, mundo!");
}

saludo(); ```

```
 Resultado: 

``` javascript
function saludo() {
  console.log("¡Hola, mundo!");
}

saludo();

```

---
### 3. Enlaces   

- Los corchetes y paréntesis `[ ]( )` sirven para crear enlaces.

**Ejemplo:**

`[Google](https://www.google.com)`

Resultado:

[Google](https://www.google.com)

---
### 4. Imagenes
- La combinación `![ ]( )` se usa para insertar imágenes.

**Ejemplo:**

```md
![Texto alternativo](/img/imagen.png)
```
  resultado: 

![Logo](/img/logo.png)

## 3. Otros caracteres útiles

### 1. URL's
- Las URL entre `< >` se convierten automáticamente en enlaces en Markdown tradicional.

**Ejemplo:**

```md
<https://www.google.com>
```
---


> **Nota:** En Docusaurus (MDX) es preferible crear enlaces usando la sintaxis:
>
> ```md
> [Google](https://www.google.com)
> ```

---
### 2. Encabezados alternativos

- También puedes crear encabezados usando `===` o `---`.

**Ejemplo:**

### Título nivel 1

**Sintaxis:**

```md
Título principal
================
```

**Resultado:**

# Título principal

---

### Título nivel 2

**Sintaxis:**

```md
Título secundario
-----------------
```

**Resultado:**

     ## Título secundario

--- 

### 3. Bloques especiales

Docusaurus permite crear **bloques informativos** para destacar contenido importante, consejos, advertencias o 
información adicional. Estos bloques se conocen como **Admonitions** y ayudan a que la documentación sea más clara y visual.

Se crean utilizando tres dos puntos (`:::`), seguidos del tipo de bloque que deseas mostrar.

| Tipo | Uso |
|------|-----|
| `note` | Información adicional o recomendaciones. |
| `tip` | Consejos o buenas prácticas. |
| `info` | Información general. |
| `warning` | Advertencias importantes. |
| `danger` | Riesgos, errores críticos o acciones peligrosas. |



**Ejemplo:**

```md
:::note 
Esto es una nota especial.
:::

:::tip
Este es un consejo útil.
:::

:::info
Esta es información importante.
:::

:::warning
Esto es una advertencia.
:::

:::danger
Ten cuidado, esta acción es irreversible.
:::
```

**Resultado:**
:::note
Esto es una nota especial.
:::

:::tip
Este es un consejo útil.
:::

:::info
Esta es información importante.
:::

:::warning
Esto es una advertencia.
:::

:::danger
Ten cuidado, esta acción es irreversible.
:::
