## Descarga

### paso 1 
 **Visita la página oficial:** Abre tu navegador y ve a 
[python](https://www.python.org/)
### paso 2
**Dirígete a la sección Descargas:** Haz clic en la pestaña "Downloads" en la parte superior del sitio. Allí verás recomendaciones 
para descargar la última versión para tu sistema operativo.

![Pagina oficial](/img/python/Pagina_oficial.png)

### paso 3
**Descarga el instalador:** Selecciona la versión recomendada para tu sistema operativo (por ejemplo, Windows, macOS o Linux) y haz clic en el enlace para descargarlo.

![Descarga](/img/python/Descarga.png)

### paso 4
**4.1 Ejecuta el instalador:** Una vez descargado el archivo, ábrelo. Si tienes una versión anterior de Python, puedes optar por reemplazarla o actualizarla.

**4.2 Sigue las instrucciones de instalación:** Acepta los términos y condiciones y haz clic en **"Siguiente"** para completar la instalación.

![Instalador](/img/python/Instalador.png)

### paso 5

**Verifica la instalación:** Abre la terminal (en Windows, puedes usar "cmd") y escribe el comando `python --version`. Esto debería mostrarte la versión de Python instalada, confirmando que la instalación fue exitosa.

![confirmacion](/img/python/confirmación.png)

## Configuración del entorno

Después de instalar Python, el siguiente paso es configurar un entorno de desarrollo donde podrás escribir y ejecutar tu código. A continuación, se describen los pasos que puedes seguir:

### paso 1
**Instala un editor de código:** Es recomendable usar un editor de código para facilitar la escritura de tus programas. Uno de los más populares es Visual Studio Code, 
que es gratuito. Ve a la página oficial de [Visual Studio](https://code.visualstudio.com/)
 y descárgalo para tu sistema operativo. Sigue las instrucciones de instalación.

![Visual studio pagina oficial](/img/python/visualstudio.png)

### paso 2
**Verifica la instalación de Python:** Abre un terminal o símbolo del sistema y escribe `python --version` para asegurarte de que Python se haya 
instalado correctamente. Esto debería mostrar la versión que instalaste.

![confirmacion](/img/python/confirmación.png)

### paso 3
**Configura un entorno virtual (opcional):** Para evitar conflictos entre diferentes proyectos, es una buena práctica configurar un entorno virtual. Puedes hacerlo 
usando el comando `python -m venv nombre_del_entorno` en el terminal. Luego, activa el entorno con el comando correspondiente para tu sistema operativo.

### paso 4
**Escribe tu primer script:** Abre tu editor de código y crea un nuevo archivo con la extensión `.py`. Puedes comenzar escribiendo un simple programa, como `print("Hola, Mundo!")`.

![script1](/img/python/script1.png)

### paso 5
**Ejecuta tu script:** Guarda el archivo y, en el terminal, navega a la carpeta donde guardaste tu script. Ejecuta el script usando el comando `python nombre_del_archivo.py`

![resultadoscript1](/img/python/resultadoscript1.png)
