Los fundamentos de Python son esenciales para cualquier persona que desee aprender a programar en este lenguaje. 

* **Sintaxis Básica:** Entender cómo se estructura un programa en Python, incluyendo el uso correcto de espacios y la eliminación del uso de puntos y comas.

* **Variables y Tipos de Datos:** Aprender a declarar variables y los diferentes tipos de datos disponibles, como números enteros, flotantes, cadenas 
de texto y booleanos.

* **Operadores:** Familiarizarte con los operadores aritméticos, lógicos, y de comparación que son fundamentales en programación.

* **Estructuras de Control de Flujo:** Uso de condicionales (if, else, elif) y bucles (for, while) para controlar el flujo del programa.

* **Funciones:** Definir y llamar funciones, así como entender el alcance de las variables y el paso de argumentos.

* **Manejo de Errores:** Aprender a utilizar bloques try y except para manejar excepciones y errores en el código.

* **Estructuras de Datos:** Conocer listas, tuplas, diccionarios y conjuntos, que te ayudarán a almacenar y manipular datos de manera efectiva.

Cada uno de estos temas es fundamental para desarrollar aplicaciones en Python y te preparará para avanzar hacia conceptos más avanzados, como la 
programación orientada a objetos y el trabajo con bibliotecas y frameworks populares.

## Sangría

La sangría en Python es un aspecto fundamental que se refiere a los espacios al comienzo de una línea de código. A diferencia de otros lenguajes de programación que
utilizan llaves para indicar el inicio y el final de un bloque de código, Python utiliza la sangría para definir la estructura lógica de un programa. 

La sangría en Python no solo mejora la legibilidad del código, sino que también es necesaria para que el código funcione correctamente. Si la sangría no es consistente, 
Python generará errores de indentación.

**Cómo usarla:** Es común usar cuatro espacios o un tabulador para la sangría, aunque debes mantener la misma técnica en todo tu código (es decir, no mezcles espacios 
y tabuladores).

En un bloque condicional if, la sangría se utiliza para indicar qué instrucciones pertenecen a esa condición. Por ejemplo:

![sangria](/img/python/sangria.png)

En este caso, `print("Diez es mayor que dos")` debe estar indentado para indicarle a Python que está dentro del bloque if. Si no lo está, recibirás un error de 
indentación cuando intentes ejecutar tu código.

## Comentarios

Los comentarios en Python son una de las buenas practicas que se hacen a la hora de programar, algunas ventajas de estos son:

- son una excelente manera de mejorar la claridad y legibilidad de tu código.

- Los comentarios se utilizan para explicar partes del código que pueden no ser claras. Esto es útil, especialmente en programas largos.

- Facilitan la entendimiento del código para otros programadores o para ti mismo en el futuro.

- Puedes comentar líneas que no deseas ejecutar temporalmente.

**Sintaxis**

- Para comentar una sola línea, puedes usar el símbolo #. Todo lo que esté a la derecha de este símbolo en la misma línea será ignorado por Python.

```
# Este es un comentario
print("Hola, Mundo!")  # Este print se ejecutará
```

- Para comentar múltiples líneas, puedes usar tres comillas (simples o dobles):

```
"""
Este es un comentario
que abarca múltiples líneas.
"""
print("Código ejecutado")

```

:::tip
Utilizar comentarios apropiadamente no solo hace que tu código sea más accesible, sino que también te ayudará a recordar la lógica detrás de ciertas decisiones o 
implementaciones cuando revises el código más adelante.
:::

## Variables

Una variable es un espacio en la memoria donde se puede almacenar un valor. En Python, puedes crear una variable simplemente asignándole un valor usando el operador 
de asignación `=`

### Tipos de variables

 - **Variables Escalares:** Almacenan un solo valor, como un número, una cadena de texto, un booleano, etc. Por ejemplo:

```
nombre = "Juan"
edad = 30
```

- **Listas:** Permiten almacenar colecciones de valores. Puedes definir una lista utilizando corchetes []:

```
colores = ["rojo", "verde", "azul"]
```
- **Diccionarios:** Almacenan pares clave-valor y se definen usando llaves {}:

```
usuario = {"nombre": "Juan", "edad": 30}
```
- **Asignación de Valores:** Puedes asignar un valor a múltiples variables en una sola línea:

```
a, b, c = "Hola", "Mundo", "!"
```

- **Operador de Asignación:** El operador `=` se utiliza para asignar valores a las variables y es fundamental comprenderlo, ya que es la manera en que defines 
qué datos almacenará cada variable.

- **Reutilización:** Gracias a las variables, puedes codificar de manera más flexible y reutilizar el mismo valor en diferentes partes del programa, lo que facilita 
el mantenimiento y actualización del código.


### Nombres de variables

Los nombres de las variables en Python deben seguir ciertas convenciones para asegurar que sean claros y comprensibles.

**Caracteres Permitidos:** Los nombres de las variables pueden contener letras (mayúsculas y minúsculas), números (0-9) y guiones bajos (_), pero no deben comenzar 
con un número.

```
variable1 = 5
_variable2 = 10
```
**Sensibilidad a Mayúsculas y Minúsculas:** Python distingue entre mayúsculas y minúsculas. Esto significa que variable, Variable y VARIABLE son considerados nombres 
diferentes.

**Nombres Descriptivos:** Es recomendable que los nombres de las variables sean descriptivos y concisos. Evita abreviaturas ambiguas para facilitar la comprensión 
del código.

```
edad = 25  # es más claro que simplemente usar 'e'
```

**Variedad de Palabras:** Si el nombre de la variable consta de varias palabras, puedes utilizar guiones bajos para separar las palabras o la convención CamelCase.

```
numero_de_estudiantes = 30
NumeroDeEstudiantes = 30  # CamelCase
```
**Evitar Palabras Reservadas:** No se pueden usar nombres de variables que son palabras reservadas en Python, tales como `if`, `else`, `for`, etc

### Valores a múltiples variables

En Python, puedes asignar valores a múltiples variables en una sola línea de código.

- **Asignación Múltiple de un Solo Valor:** Puedes asignar el mismo valor a varias variables usando una sola línea:

En este caso, las variables a, b y c tendrán el valor "Hola".

```
a = b = c = "Hola"
```

- **Asignación Múltiple de Diferentes Valores:** También puedes asignar diferentes valores a múltiples variables al mismo tiempo:

Aquí, x contendrá 1, y contendrá 2 y z contendrá 3. 
```
x, y, z = 1, 2, 3
```
- **Usando Colecciones:** Si tienes una colección, como una lista o una tupla, puedes descomponer los valores en variables:

Estas técnicas te permiten trabajar de manera más eficiente y concisa al manipular múltiples valores en Python.

```
paises = ["Panama", "Brasil", "Alemania"]
x, y, z = paises  # x será "Panama", y será "Brasil", z será "Alemania"
```

## Tipos de datos númericos

- **Enteros (int):** Representan números enteros, positivos o negativos, sin decimales. 

```
numero_entero = 10
```

- **Flotantes (float):** Almacenan números con decimales. Ejemplo:

```
numero_flotante = 10.5
```

- **Números complejos (complex):** Compuestos por una parte real y una parte imaginaria. Se indican utilizando la letra j o J para la parte imaginaria. Ejemplo:

```
numero_complexo = 2 + 3j
```

- **Decimal (decimal.Decimal):** Este tipo se utiliza para representar números decimales con mayor precisión, especialmente útil en situaciones financieras. 
Requiere importar el módulo decimal:
```
from decimal import Decimal
precio = Decimal('10.99')
```

- **BigInt (int en Python 3):** Python 3 no tiene un tipo separado para grandes enteros, ya que el tipo int puede manejar números de tamaño arbitrario.

## Operadores

En Python, los operadores se utilizan para realizar diversas operaciones en variables y valores.

**Operadores Aritméticos:** Utilizados para realizar operaciones matemáticas básicas.

- ` +` (suma): Suma dos números.
- `-` (resta): Resta el segundo número del primero.
- `*` (multiplicación): Multiplica dos números.
- `/` (división): Divide el primer número entre el segundo. Ten en cuenta que el resultado es un número de punto flotante (float).
- `%` (módulo): Devuelve el resto de una división.


```
suma = 5 + 3  # Resultado: 8
resta = 5 - 3  # Resultado: 2

x = 10
y = 5
multiplicacion = x * y  # Resultado: 50

x = 10
y = 5
division = x / y  # Resultado: 2.0

x = 10
y = 3
modulo = x % y  # Resultado: 1
```

**Operadores de Comparación:** Comparan dos valores y devuelven un resultado booleano (True o False).

- `==` (igual a): Comprueba si dos valores son iguales.
- `!=` (no igual a): Comprueba si dos valores son diferentes.
- `>` (mayor que): Comprueba si el valor de la izquierda es mayor que el de la derecha.
- `<` (menor que): Comprueba si el valor de la izquierda es menor que el de la derecha.
- `>=` (mayor o igual que): Comprueba si el valor de la izquierda es mayor o igual al de la derecha.
- `<=` (menor o igual que): Comprueba si el valor de la izquierda es menor o igual al de la derecha.


```
a = 5
b = 5
resultado = (a == b)  # Resultado: True

a = 5
b = 3
resultado = (a != b)  # Resultado: True

a = 5
b = 3
resultado = (a > b)  # Resultado: True

a = 3
b = 5
resultado = (a < b)  # Resultado: True

a = 5
b = 5
resultado = (a >= b)  # Resultado: True

a = 3
b = 5
resultado = (a <= b)  # Resultado: True
```

**Operadores de Asignación:** Se utilizan para asignar un valor a una variable.

- `=` (asignación simple): Asigna el valor de la derecha a la variable de la izquierda.
- `+=` (asignación y suma): Suma el valor a la variable y luego asigna el resultado a la misma variable. Equivale a x = x + valor. 
- `-=` (asignación y resta): Resta el valor de la variable y luego asigna el resultado.
- `*=` (asignación y multiplicación): Multiplica la variable por el valor y luego asigna el resultado a la misma variable.
- `/=` (asignación y división): Divide la variable por el valor y luego asigna el resultado.

```
x = 5  # Asigna 5 a la variable x

x = 5
x += 2  # x ahora es 7

x = 5
x -= 2  # x ahora es 3

x = 5
x *= 2  # x ahora es 10

x = 10
x /= 2  # x ahora es 5.0
```

**Operadores Lógicos:** Se utilizan para realizar operaciones lógicas entre valores booleanos.

- `and:` Este operador devuelve True si ambas condiciones son verdaderas. Si alguna de las condiciones es falsa, devolverá False.
- `or:` Este operador devuelve True si al menos una de las condiciones es verdadera. Solo devolverá False si ambas condiciones son falsas.
- `not:` Este operador invierte el valor de una condición. Si la condición es verdadera, not la convertirá en falsa, y viceversa.

```
a = True
b = False
resultado = a and b  # Resultado: False


a = True
b = False
resultado = a or b  # Resultado: True


a = True
resultado = not a  # Resultado: False
```

**operadores de membresia** 
Estos operadores se utilizan para comprobar si un valor está presente en una secuencia (como listas, tuplas, o cadenas). Los operadores de membresía son:

- `in:` Retorna True si el valor está presente en la secuencia.
- `not in:` Retorna True si el valor no está presente en la secuencia.

```
frutas = ['manzana', 'banana', 'naranja']
print('manzana' in frutas)  # Resultado: True
print('pera' not in frutas)  # Resultado: True
```
**operadores de identidad**

Estos operadores se utilizan para comparar la identidad de dos objetos, es decir, si ambos hacen referencia al mismo objeto en la memoria. Los operadores de identidad son:

- `is:` Retorna True si ambas variables apuntan al mismo objeto.
- `is not:` Retorna True si ambas variables no apuntan al mismo objeto.

```
a = [1, 2, 3]
b = a
c = list(a)

print(a is b)      # Resultado: True (b es una referencia al mismo objeto que a)
print(a is c)      # Resultado: False (c es un nuevo objeto en memoria)
print(a == c)      # Resultado: True (los valores son iguales)
```

## Condicionales

En Python, las estructuras condicionales son fundamentales para controlar el flujo de tu programa y tomar decisiones basadas en condiciones.

### if else
  se utilizan para ejecutar bloques de código basados en la evaluación de una condición.

```
hora = 14
if hora < 12:
    print("Buenos días.")
else:
    print("Buenas tardes.")
```
Este código imprimirá "Buenas tardes." porque la condición hora < 12 es falsa.

### if
 Se utiliza para evaluar una condición. Si la condición es verdadera, se ejecuta el bloque de código correspondiente.

```
edad = 18
if edad >= 18:
    print("Eres mayor de 18 años.")
```
Si la condición es verdadera, se ejecuta el bloque que muestra el mensaje "Eres mayor de 18 años."


### else
 Se emplea para ejecutar un bloque de código si la condición del if es falsa.

```
if edad >= 18:
    print("Eres mayor de 18 años.")
else:
    print("No eres mayor de 18 años.")
```

Si la condición es falsa, se ejecuta el bloque que muestra el mensaje "No eres mayor de 18 años." 

### elif (else if) 
Permite agregar múltiples condiciones. Se evalúa solo si las anteriores son falsas.

```
hora = 10
if hora < 12:
    print("Buenos días.")
elif hora < 18:
    print("Buenas tardes.")
else:
    print("Buenas noches.")
```
Si la condición hora `< 12` es verdadera, ejecuta el bloque que imprime "Buenos días." e ignora el resto del código.

###  ciclo while 
Se utiliza para ejecutar repetidamente un bloque de código mientras una condición específica sea verdadera. 

```
contador = 0
while contador < 5:
    print("El contador es:", contador)
    contador += 1  # Incrementa el contador
```
La respuesta esperada seria: Después de imprimir hasta 4, el bucle se detendrá cuando contador llegue a 5, haciendo que la condición contador `< 5` sea falsa.

```
El contador es: 0
El contador es: 1
El contador es: 2
El contador es: 3
El contador es: 4

```

### ciclo for
Utilizada para iterar sobre una secuencia (como una lista, tupla, diccionario, conjunto o cadena) o un rango de números. 

```
frutas = ["manzana", "banana". "pera"]
for fruta in frutas:
    print(fruta)
```
Este imprimira: 

```
manzana
banana
pera
```

## Funciones

Las funciones en programación son bloques de código reutilizables que realizan tareas específicas.

**Características de las funciones**

* **Reutilizables:** Una vez que defines una función, puedes llamarla tantas veces como necesites, lo que evita la repetición de código.
* **Parámetros:** Pueden aceptar datos de entrada, conocidos como parámetros, que les permiten trabajar con diferentes valores.
* **Retorno de valores:** Pueden devolver un resultado luego de ejecutar su tarea, lo que permite utilizar el resultado en otras partes del código.

**Sintaxis**

```
def nombreFuncion():
    print("Hola mundo")
```
Ejemplo:

Esta es una función que indica si el auto esta encendido o apagado

```
def encender(estado): 
    if estado == 1:
        print("El auto ya esta encendido")
    else:
        print("Auto encendido")


def apagar(estado):
    if estado == 1:
        print("Auto apagado")
    else:
        print("No se puede apagar, porque ya esta apagado")

encender(1)

```
Este código imprimirá:

```
El auto ya esta encendido
```

**explicación:**

1. Al llamar a encender(1), la variable estado toma el valor 1.

2. Se evalúa la condición `if estado == 1: ` (¿1 == 1?). Como es verdadera (True), ejecuta print("El auto ya esta encendido").

3. El bloque else se ignora por completo.

### Tipos de funciones

* **Funciones nombradas:** Estas son funciones que tienen un nombre específico y se pueden invocar por este nombre. Su uso facilita la comprensión del código. Por ejemplo:

```
def suma(a, b):
    return a + b
```
* **Funciones anónimas:** También conocidas como "lambda functions", no tienen un nombre y a menudo se utilizan para tareas sencillas. Por ejemplo, en Python, podemos definir una función anónima que suma dos números así:

```
suma = lambda a, b: a + b
```
* **Métodos:** En programación orientada a objetos, las funciones a menudo se definen dentro de una clase y se denominan métodos.

```
class Calculadora:
    def sumar(self, a, b):
        return a + b
```
* **Funciones de orden superior:** Son funciones que pueden recibir otras funciones como argumentos o devolver funciones como resultado. Esto permite crear funciones más dinámicas y versátiles.

* **Funciones recursivas:** Son aquellas que se llaman a sí mismas dentro de su definición. Se utilizan para problemas que se pueden dividir en subproblemas más pequeños, como el cálculo de factoriales.

* **Funciones estáticas y de instancia:** En el contexto de la programación orientada a objetos, las funciones pueden ser estáticas, lo que significa que no requieren 
una instancia de la clase para ser llamadas, o funciones de instancia, que operan sobre instancias específicas de la clase.

## Módulos

En Python, los módulos son archivos que contienen definiciones y declaraciones de Python. Permiten organizar el código y reutilizar funciones y clases en diferentes programas.

```
import nombre_del_modulo

```
* **Creación de Módulos:**  Un módulo puede ser creado simplemente guardando un archivo con la extensión .py. El archivo puede contener funciones, clases y variables 
    que pueden ser utilizadas en otros archivos.

* **Uso de Funciones y Clases:** Tras importar un módulo, puedes acceder a sus funciones y clases usando la sintaxis `nombre_del_modulo.nombre_de_la_funcion()`.
    Módulos Built-in: Python incluye muchos módulos incorporados, como math para funciones matemáticas, os para interactuar con el sistema operativo, y datetime para manejar fechas y horas.

* **Módulos Built-in:** Python incluye muchos módulos incorporados, como math para funciones matemáticas, os para interactuar con el sistema operativo, y datetime para manejar fechas y horas.

* **Módulos de Terceros:** Puedes instalar y usar módulos que no son parte de la biblioteca estándar mediante herramientas como pip.

```
# operaciones archivo 1

def sumar(a,b):

import operaciones

res_sum = operaciones.sumar(10,30)
    print(res_sum)
```

## Listas

Las listas en Python son estructuras de datos que permiten almacenar múltiples elementos, que pueden ser de tipos variados (números, cadenas, etc.).


```
mi_Lista = ["hola", "como", "estas"]

print(mi_Lista[2])
```
### Funciones

* **Creación de Listas:** Se pueden crear utilizando corchetes `[]`

    Por ejemplo: `mi_lista = [1, 2, 3, 4]`
    
* **Agregar Elementos:**
        - Al Final: `Usa append()` Esto agrega un elemento al final de la lista.
    
    por ejemplo: `mi_lista.append(5)`
        - Al Inicio: Usa `insert()`, pasando el índice donde deseas insertar el elemento.
    
    por ejemplo: `mi_lista.insert(0, 0)  # Agrega 0 al inicio`

* **Eliminar Elementos:** 

        - Puedes utilizar `remove()` para eliminar un elemento específico.

    por ejemplo: `mi_lista.remove(2)  # Elimina el primer elemento con valor 2`

        - Puedes utilizar `pop()` para eliminar el elemento que este en la posición indicada.

    por ejemplo: `elemento_invalido = mi_lista.pop(3)  # Esto generará un IndexError si la lista no tiene un cuarto elemento.`

* **Ordenar y Revertir:** Puedes ordenar la lista usando `sort()` para ordenarla y `reverse()` para invertir el orden de los elementos.

    por ejemplo: 

    ```
    mi_lista.sort()  # Ordena la lista
    mi_lista.reverse()  # Invierte el orden     
    ```

* **Obtener el Tamaño:** Usa `len()` para obtener la cantidad de elementos en la lista.

    por ejemplo: `tamaño = len(mi_lista)`

* **Acceso a Elementos:** Puedes acceder a un elemento específico utilizando su índice.

    por ejemplo: `primer_elemento = mi_lista[0]`

:::info
Las listas se cuentan desde cero, es decir que si tengo ["hola", "como", "estas"] cuenta :  0 (hola), 1(como), 2(estas) 
:::

## Tuplas 

Una tupla en Python es una colección ordenada e inmutable de elementos, lo que significa que una vez que se crea, no se puede modificar (no puedes agregar, eliminar o cambiar elementos). 

### Conceptos claves

* **Creación de Tuplas:** Se crean utilizando paréntesis (). 

    por ejemplo: `mi_tupla = (1, 2, 3, 'hola')`

* **Acceso de Elementos:** Puedes acceder a los elementos utilizando índices, similar a las listas

    Por ejemplo: `primer_elemento = mi_tupla[0]  # Devuelve 1`

* **Desempaquetado:** Puedes asignar los elementos de una tupla a variables individuales.

    Por ejemplo: `(nombre, edad, lenguaje) = ('Juan', 25, 'Python')`

* **Longitud de tuplas:** Puedes obtener la longitud de una tupla usando la función `len()`.

    Por ejemplo: `tamaño = len(mi_tupla)  # Devuelve el número de elementos en la tupla`

* **Combinación de tuplas:** Es posible combinar dos o más tuplas creando una nueva.

    Por ejemplo: 

    ```
    tupla1 = (1, 2, 3)
    tupla2 = (4, 5, 6)
    tupla_combinada = tupla1 + tupla2  # Devuelve (1, 2, 3, 4, 5, 6)
    ```

* **Iteración:** Puedes iterar sobre los elementos de una tupla utilizando un bucle `for`.

    Por ejemplo: `for elemento in mi_tupla: print(elemento)`

* **Comprobación de existencia:** Puedes verificar si un elemento está presente en la tupla utilizando la palabra clave `in`.

    Por ejemplo: `existe = 2 in mi_tupla  # Devuelve True o False`

* **Retornar valores como tuplas:** Retornar valores como tuplas en Python es una técnica útil cuando deseas devolver múltiples resultados desde una función

    Por ejemplo:
    ```
    # definir la función

    def coordenadas():
    x = 10
    y = 20
    return x, y  # Retornamos x e y como una tupla

    # llamar la función

    resultado = coordenadas()  # resultado ahora es (10, 20)

    # desempaquetar los valores

    x, y = resultado

    # Mostrar los resultados

    print(f"X: {x}, Y: {y}")  # Muestra X: 10, Y: 20

    ```

:::info
Las tuplas son útiles cuando necesitas un grupo de elementos que no deben cambiar durante la ejecución de tu programa.
:::

## Diccionarios


Un diccionario en Python es una colección desordenada de pares clave-valor.

### Conceptos principales

* **Creación de diccionarios:** Puedes crear un diccionario utilizando llaves `{}` y definiendo las claves y valores.

    Por ejemplo:

```
mi_diccionario = {
    'nombre': 'Juan',
    'edad': 45,
    'ciudad': 'Madrid'
}
```

* **Acceso a valores:** Puedes acceder a los valores utilizando su clave.

    Por ejemplo:

    `print(mi_diccionario['nombre'])  # Muestra 'Juan'``

* **Agregar o modificar elemento:** Puedes agregar nuevos pares clave-valor o modificar un valor existente.

    Por ejemplo:
    ```
    mi_diccionario['pais'] = 'España'  # Agrega un nuevo elemento
    mi_diccionario['edad'] = 50       # Modifica el valor de edad
    ```
* **Eliminar elementos:** Para eliminar un par clave-valor, puedes usar el método `pop()`.

    Por ejemplo: `edad_eliminada = mi_diccionario.pop('edad')  # Elimina y devuelve el valor de 'edad'`

* **Verificación de existencia:**  Puedes comprobar si una clave existe en el diccionario con la palabra clave `in`.

    Por ejemplo: `existe = 'nombre' in mi_diccionario  # Devuelve True`

* **Recorrer direcciones:** Utiliza un bucle for para recorrer todos los elementos del diccionario. Puedes obtener tanto la clave como el valor usando el método `items()`.

    Por ejemplo: 
    

    ```
    for clave, valor in mi_diccionario.items():
    print(f'{clave}: {valor}')
    ```

* **Funciones ùtiles:** Muchos métodos están disponibles para diccionarios, como `keys()` que devuelve todas las claves y `values()` que devuelve todos los valores.

    Ejemplo:

        ```
        # Creación de diccionario

        persona = {
            'nombre': 'Juan',
            'edad': 30,
            'ciudad': 'Madrid'
        }

        # obtener claves

        claves = persona.keys()  # Devuelve: dict_keys(['nombre', 'edad', 'ciudad'])
        print(claves)

        # obtener valores

        valores = persona.values()  # Devuelve: dict_values(['Juan', 30, 'Madrid'])
        print(valores)

        # imprime tanto las claves como los valores.

        for clave in persona.keys():
        print(f'Clave: {clave}, Valor: {persona[clave]}')


        ```

        Resultado:
        ```
        Clave: nombre, Valor: Juan
        Clave: edad, Valor: 30
        Clave: ciudad, Valor: Madrid
        ```
