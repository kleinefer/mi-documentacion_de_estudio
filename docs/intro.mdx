# INTRODUCCIÓN

Esta documentación nace como un espacio de aprendizaje compartido.

Aquí encontrarás notas, conceptos y prácticas construidas durante mi proceso de formación como **QA Engineer (de nivel cero a avanzado)** y
**desarrollo móvil con Flutter (de principiante a experto)**. No es teoría perfecta ni contenido académico rígido; es aprendizaje real,
con aciertos, errores y ajustes en el camino.

El objetivo es simple: que este material sirva como guía para otras personas que también estén empezando o reforzando su camino en tecnología. 
Si estás aquí, probablemente estás en el mismo punto: construyendo desde cero, entendiendo paso a paso y buscando claridad en medio de tanta información.

Todo lo que verás aquí está pensado para ser práctico, directo y entendible. Sin relleno. Sin complicaciones innecesarias. Solo lo esencial para avanzar.
Porque aprender no debería sentirse como un laberinto, sino como un camino que se recorre mejor cuando alguien deja huellas antes.

## Docusaurus

**Base de aprendizaje.**

Docusaurus es un generador de sitios estáticos basado en **React**, diseñado para crear documentación 
técnica y blogs de manera rápida y organizada.  
Su objetivo es que cualquier equipo pueda levantar un portal de documentación sin necesidad de configurar todo desde cero.

En este documento trabajamos con los siguientes puntos:

## Markdown

- Qué es Markdown  
- Sintaxis básica: títulos, listas, enlaces, imágenes, tablas  
- Diferencia entre `.md` y `.mdx`  
- Ejemplos prácticos de uso  

## MDX

- `.mdx` = Markdown + JSX  
- Permite usar componentes de React dentro de la documentación  
- Bloques especiales en Docusaurus

## Manual QA Engineer

    QA significa Quality Assurance (Aseguramiento de la Calidad). Es una disciplina dentro del desarrollo de software 
    y de procesos tecnológicos que se encarga de garantizar que los productos cumplan con los estándares de calidad 
    antes de ser entregados a los usuarios o clientes.

**Base del aprendizaje**.


Todo el contenido está organizado siguiendo este esquema:

-Introducción
- Fundamentos de QA
- Ciclo de vida del software (SDLC / STLC)
- Tipos de pruebas (manuales y automatizadas)
- Diseño de casos de prueba
- Pruebas de API
- Herramientas de testing
- Automatización de pruebas
- CI/CD aplicado a QA
- Buenas prácticas en entornos reales

## Flutter - Móvil: De cero a experto

Flutter es un framework de desarrollo de aplicaciones móviles multiplataforma creado por Google. Permite construir 
apps para Android, iOS, Web y escritorio usando un solo código base, lo que ahorra tiempo y esfuerzo a los desarrolladores.

**Base de apendizaje**
